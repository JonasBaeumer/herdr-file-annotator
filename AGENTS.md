# AGENTS.md

## Reviewing a diff in this repo

**Read `REVIEWS.md` before reviewing.** It carries the full review
guidelines: how to derive and confirm the business rule a diff asserts, the
P0 and P1 severity lists, the Rust and tooling rules specific to this repo,
and the recurring domain ambiguities to ask about.

This applies to any review task — a pull request, a diff handed over by an
agent, or a pre-merge check. Do not review from this file alone.
